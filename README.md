# MENSPIRE / 智男學舍

> **掌握資源主權，重新定義男性價值。**  
> A platform dedicated to male self-improvement, financial sovereignty, personal growth, and healthy relationship dynamics.

---

## 📖 專案簡介 (About The Project)

**MENSPIRE** 是一個專為現代男性打造的自我提升與資源管理社群平台。

在當代社會文化與消費主義影響下，許多男性常陷入討好型消費與情緒勒索的困境。本平台旨在推廣「理性經濟人」與「自我價值重構」理念，引導男性將有限的血汗錢與時間，優先投資於**個人升級**（健康、技能、事業）、**興趣資產**（車輛、科技裝備）以及**孝順父母**上，從而建立真實的底氣與尊嚴。

---

## 💡 核心價值觀 (Core Pillars)

1. **資源主權與財務獨立 (Financial Sovereignty)**
   * 拒絕當「行走 ATM」與討好型消費。
   * 建立健康的個人資產配置，掌控自身財務支配權。
2. **自我升級與硬實力 (Self-Improvement)**
   * 健身、穿搭與個人形象管理。
   * 職業技能、知識儲備與副業發展。
   * 享受專屬於男性的個人興趣與生活質素（如汽車駕駛樂趣、Gadget 等）。
3. **孝親與家庭責任 (Family & Gratitude)**
   * 優先回饋原生家庭，重視養育之恩與孝親責任。
4. **健康邊界與平等關係 (Healthy Boundaries)**
   * 倡導男女雙方在感情中權利與義務對等。
   * 以個人魅力與底氣吸引伴侶，而非靠經濟補貼維持關係。

## 🚀 快速開始 (Getting Started)

### 前置需求 (Prerequisites)
* Node.js (v18.0.0 或以上)
* npm 或 yarn

### 安裝步驟 (Installation)

1. 複製專案庫 (Clone the repository)：
   ```bash
   git clone https://github.com/your-username/menspire-platform.git
   cd menspire-platform
   ```

2. 安裝依賴包 (Install dependencies)：
   ```bash
   npm install
   ```

3. 啟動本地開發伺服器 (Run development server)：
   ```bash
   npm run dev
   ```

4. 開啟瀏覽器訪問 `http://localhost:3000` 即可檢視網站。
